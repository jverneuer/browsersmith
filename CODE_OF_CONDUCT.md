# Code of Conduct

## Our standard

Be decent. Every member of this community — issues, pull requests, Discussions, code review, docs — is expected to:

- **Be kind and respectful.** No harassment, hate speech, slurs, trolling, or personal attacks. Ever.
- **Assume good faith.** Questions are not challenges; naive reports are not noise.
- **Criticize code, not people.** "This approach leaks the real fingerprint" — good. "You're an idiot" — not.
- **Keep it useful.** No spam, no advertising, no off-topic dumps.
- **Respect disagreement.** Technical disputes get settled by tests and evidence, not volume.

## Scope

This applies to all project spaces: issues, pull requests, Discussions, code and docs in the repositories, and anywhere you represent the project (e.g. quoting maintainer responses elsewhere).

## Enforcement

Violations can be reported privately to the maintainer via [GitHub private vulnerability reporting](https://github.com/jverneuer/browsersmith/security/advisories/new) on the browsersmith repo (write "Code of Conduct" in the title) — it's the only reliably private channel GitHub offers. Reports are reviewed and kept confidential.

The maintainer may edit or remove comments, close contributions, or ban a participant from project spaces for conduct violations. Decisions are explainable but final.
